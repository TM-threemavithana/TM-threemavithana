## 🚀 Featured Engineering Work

### 🔒 [AgentIAM](https://github.com/TM-threemavithana/agentiam)

A zero-trust SQL firewall designed to safely control database queries generated by LLM-powered agents.

It parses SQL into an **Abstract Syntax Tree (AST)** and applies validation and policy enforcement before queries are allowed to reach the database.

**Key areas:** AI Security · SQL Security · Policy Enforcement · Backend Systems

**Tech:** `Go` · `PostgreSQL` · `Kubernetes`

---
